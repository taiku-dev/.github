# taiku

Your machine, in a tab. Send a link to your live terminal and the people you send it to can watch, type or manage
it, along with whatever runs beside it, like a local web preview, a remote desktop, shared documents and the coding
agents working in those terminals.

- [Share a session](https://docs.taiku.live/docs/guides/sessions). Choose who can watch, type, or manage it.
- [Multiplayer editing](https://docs.taiku.live/docs/guides/collaboration). The same terminals and documents, live, with shared presence.
- [Share a local web preview](https://docs.taiku.live/docs/guides/tunnels). Publish a local web app or API through your session.
- [Remote desktop](https://docs.taiku.live/docs/guides/remote-desktop). Open a streamed desktop from a session and take control.
- [AI agents](https://docs.taiku.live/docs/guides/agents). taiku detects coding agents in your terminals, tracks their status, and tells you the moment one needs you.
- [See why a line exists](https://docs.taiku.live/docs/guides/why-a-line-exists). Find the agent turn and the request behind any line of code.
- [Remote dev machines](https://docs.taiku.live/docs/guides/cloud-workspaces). A managed Linux or Windows machine for a project, with a durable link.
- [Mobile apps](https://docs.taiku.live/docs/guides/mobile). Join, drive, and monitor sessions from your phone or tablet.

## Install

    curl -sSf https://taiku.live/get | sh

Homebrew: `brew install taiku-dev/tap/taiku`. Windows (PowerShell): `irm https://taiku.live/get.ps1 | iex`.
Then [start your first session](https://docs.taiku.live/docs/quickstart).
